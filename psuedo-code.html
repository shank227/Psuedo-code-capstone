// Pseudo-code 

Main Program:
  Initialize DatabaseHandler
  Initialize EmailPreprocessor
  Initialize LSTMClassifier
  Initialize GraphConstructor
  Initialize GCNModel
  Initialize PhishingDetector
  Initialize UserInterface

  Loop: Wait for User/Admin to upload or scan email
    email = UserInterface.uploadEmail()
    preprocessedText = EmailPreprocessor.cleanText(email.body)
    tokenizedText = EmailPreprocessor.tokenize(preprocessedText)
    textFeatures = EmailPreprocessor.vectorize(tokenizedText)
    
    lstmPrediction = LSTMClassifier.predict(textFeatures)
    
    emailGraph = GraphConstructor.buildGraph(email.metadata)
    gcnPrediction = GCNModel.predict(emailGraph)
    
    finalResult = PhishingDetector.integratePredictions(lstmPrediction, gcnPrediction)
    
    DatabaseHandler.saveEmail(email, preprocessedText, textFeatures, emailGraph, finalResult)
    
    UserInterface.displayResult(finalResult)

Training Module:
  Loop: For each training epoch
    trainingDataText, trainingDataGraph = fetchTrainingData()
    
    LSTMClassifier.train(trainingDataText)
    GCNModel.train(trainingDataGraph)
    
    Validate models and fine-tune parameters

Submodules:

EmailPreprocessor:
  Function cleanText(text):
    Remove noise, special characters, lower casing
    Return cleaned text

  Function tokenize(text):
    Split text into tokens (words)
    Return tokens array

  Function vectorize(tokens):
    Convert tokens to numerical vectors using embeddings
    Return feature vectors

LSTMClassifier:
  Function train(data):
    Train LSTM model using sequential email text data

  Function predict(features):
    Output phishing probability based on text

GraphConstructor:
  Function buildGraph(metadata):
    Create nodes for sender, receiver, domains, etc.
    Create edges for connections in communication
    Return graph data structure

GCNModel:
  Function train(graphData):
    Train GCN using structural graph data

  Function predict(graph):
    Output phishing probability based on structure

PhishingDetector:
  Function integratePredictions(lstmPred, gcnPred):
    Combine predictions (e.g., weighted average or stacking)
    Classify email as phishing or legitimate
    Return final classification

DatabaseHandler:
  Functions for saving and retrieving email data and results

UserInterface:
  Functions for uploading emails and displaying results
